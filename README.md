## `> Sobre mim`

Sou **Allan Gustavo**, desenvolvedor **Frontend e Backend**.

Meu foco está no desenvolvimento de aplicações e interfaces utilizando tecnologias modernas do ecossistema web, trabalhando tanto na construção do **frontend** quanto na lógica e estrutura do **backend**.

Atualmente, meus principais estudos e projetos envolvem:

- Desenvolvimento de interfaces web
- Aplicações com React e Next.js
- Desenvolvimento backend com Node.js, Python e Java
- Criação de projetos completos para prática e portfólio
- Desenvolvimento utilizando JavaScript e TypeScript

> **Código limpo, interfaces bem construídas e evolução constante.**
